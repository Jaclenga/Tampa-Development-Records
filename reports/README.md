# Reports

Generated and run-specific outputs live here; explanatory documentation lives
in [`docs/`](../docs/README.md).

| Path | Contents |
| --- | --- |
| `changes/` | Human-readable monthly snapshot comparisons |
| `dashboard/` | Static HTML comparison dashboard and detail pages |
| `validation/` | Current machine-readable QA and validation reports |
| `agentic_runs/` | Immutable run artifacts from the bounded agent experiment |
| `AGENTIC_VALIDATION_REPORT.md` | Frozen summary tied to the benchmark freeze |

The agentic report and the evaluated run directories intentionally retain their
existing names because their exact paths are recorded in
`reproducibility/agent_benchmark_freeze_v1.json`.
