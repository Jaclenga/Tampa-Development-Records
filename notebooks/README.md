# Public exploration notebooks

| Notebook | Purpose |
| --- | --- |
| [`tampa_development_exploration.ipynb`](tampa_development_exploration.ipynb) | Dependency-light introduction to temporal cohorts, source/date semantics, neighborhood aggregates, missingness, and the first snapshot comparison. |

The notebook reads repository files locally when run from a checkout. When
opened through its Colab badge, it falls back to public files pinned to the
documented Git revision. It does not display street addresses or other
record-level location details.

Run all cells from top to bottom with a Python 3 kernel. No packages beyond the
standard Jupyter/IPython environment are required.
