# Verification data

`verification_summary.csv` is generated by:

```bash
python scripts/build_verification_summary.py
```

It summarizes distinct verification layers without creating a composite score
or record-level `verified` boolean. Blank numeric fields mean **not measured**,
not zero. Record-level first and second human-review assignments and evidence
fields remain in `data/processed/manual_validation_*.csv`; historical pilot
evidence remains in `data/processed/external_verification_pilot.csv`.
